# Clean and Minimalist Website Template

This repository contains the source code for the website template used by my project websites and personal webpage.

Examples of using this template include:
- https://howardxiao.ca/speed/
- https://howardxiao.ca/foveated/
- https://howardxiao.ca/

Feel free to use this template. Please reference and link back to this repository in your website footer.

## For Agentic Use
After cloning the repository, move the `clean-website/` folder into your `skills/` directory. It includes `SKILL.md`, which allows an agent to use this template automatically when a user wants to create a webpage.
